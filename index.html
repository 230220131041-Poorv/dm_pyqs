Q 1Justify the importance of data mining.

Definition

Data Mining is the process of discovering interesting patterns, correlations, anomalies, and useful knowledge from large amounts of data stored in databases, data warehouses, or other information repositories.

Why Data Mining is Important

🔍 Knowledge Discovery

Extracts hidden patterns and relationships from massive datasets that cannot be found manually.

📈 Business Intelligence

Helps organizations make data-driven decisions, predict customer behavior, and increase profits.

🏥 Healthcare

Disease pattern detection, drug interaction analysis, patient outcome prediction.

🛡️ Fraud Detection

Banks and financial institutions use data mining to detect unusual transaction patterns indicating fraud.

🛒 Market Basket Analysis

Retailers identify which products are frequently bought together to optimize product placement.

🌐 Web Mining

Improves search engines, recommendation systems (Netflix, Amazon), and targeted advertising.

Justification — Data Explosion

The world generates 2.5 quintillion bytes of data daily. Traditional database query tools cannot extract meaningful insight from this volume. Data mining bridges the gap between data and knowledge.

KDD Pipeline: Raw Data → Data Cleaning → Integration → Selection → Transformation → Data Mining → Pattern Evaluation → Knowledge

Key Applications

  • Customer churn prediction in telecom
  • Credit scoring and loan approval in banking
  • Medical diagnosis and genomics
  • Intrusion detection in cybersecurity
  • Supply chain optimization
📌 Data mining turns raw data into actionable intelligence — it is the engine of the modern data-driven economy.
Q 2Briefly discuss steps of KDD process.

KDD — Knowledge Discovery in Databases

KDD is the overall process of discovering useful knowledge from data. Data Mining is just one step in the KDD process.

KDD Process Flow

Steps in Detail

  1. Data Cleaning: Remove noise, handle missing values, correct inconsistencies in raw data.
  2. Data Integration: Combine data from multiple heterogeneous sources (databases, flat files, OLAP) into a unified store.
  3. Data Selection: Retrieve only the data relevant to the analysis task from the database.
  4. Data Transformation: Convert data into appropriate mining forms — normalization, aggregation, generalization.
  5. Data Mining: Apply intelligent methods (classification, clustering, association rules) to extract patterns.
  6. Pattern Evaluation: Identify truly interesting patterns based on interestingness measures (support, confidence, lift).
  7. Knowledge Presentation: Visualize and present the mined knowledge to the user using charts, rules, trees.
📌 Exam tip: KDD = the entire pipeline. Data Mining = step 5 only. Many students confuse the two.
Q 3Explain data reduction and dimensionality reduction.

Data Reduction

Data Reduction is the process of obtaining a reduced representation of the dataset that produces the same (or almost same) analytical results. The goal is to reduce storage and processing time while preserving data integrity.

Techniques of Data Reduction

Dimensionality Reduction

Reduce the number of attributes/features. Methods: PCA, wavelet transforms, feature selection.

Numerosity Reduction

Reduce data volume by choosing alternative, smaller data representations. E.g., regression models, histograms, clustering.

Data Compression

Use encoding mechanisms to reduce data size. Lossless (ZIP) and lossy (image compression) techniques.

Data Cube Aggregation

Summarize data at higher concept levels — e.g., daily sales → monthly sales → yearly sales.

Dimensionality Reduction

Dimensionality Reduction specifically reduces the number of attributes (features/variables) in a dataset. High-dimensional data suffers from the "curse of dimensionality" — too many features make learning slow and inaccurate.

Principal Component Analysis (PCA)

PCA transforms correlated variables into a set of uncorrelated variables called principal components, ordered by the amount of variance they explain. Only the top k components (explaining most variance) are kept.

New Attributes = Linear combinations of original attributes PC1 = direction of maximum variance PC2 = direction of second maximum variance (⊥ to PC1)

Attribute Subset Selection

Remove irrelevant or redundant attributes. Methods: stepwise forward/backward selection, decision-tree-based selection.

Dimensionality Reduction — 3D to 2D via PCA
📌 Dimensionality reduction is a subset of data reduction. It specifically targets the number of features, not the number of records.
Q 4What do you mean by correlation analysis? Justify its importance.

Correlation Analysis

Correlation Analysis measures the statistical relationship (degree of association) between two or more attributes/variables. It determines whether changes in one variable are associated with changes in another.

Types of Correlation

Positive Correlation

Both variables increase together. E.g., Height and Weight.

Negative Correlation

One increases as other decreases. E.g., Speed and Travel time.

No Correlation

No linear relationship. E.g., Shoe size and IQ.

Pearson's Correlation Coefficient

r = Σ[(xᵢ - x̄)(yᵢ - ȳ)] / √[Σ(xᵢ - x̄)² × Σ(yᵢ - ȳ)²] Range: -1 ≤ r ≤ +1 r = +1 : Perfect positive correlation r = -1 : Perfect negative correlation r = 0 : No correlation

Chi-Square Test for Nominal Data

χ² = Σ [(Observed - Expected)² / Expected] If χ² > threshold → attributes are correlated

Importance in Data Mining

  • Feature Selection: Remove highly correlated (redundant) features to reduce dimensionality
  • Anomaly Detection: Unexpected correlations can indicate data errors or interesting patterns
  • Association Rule Mining: Correlation helps identify meaningful associations vs spurious ones
  • Preprocessing: Guides data transformation and normalization decisions
  • Classification: Correlated features may cause multicollinearity problems in models
📌 Correlation does NOT imply causation. Two variables can be correlated without one causing the other.
Q 5Define: concept description, support, confidence, strong association rules, data generalization, unsupervised learning.

Key Definitions

1. Concept Description

Concept description is the characterization and discrimination of a class/concept. Characterization summarizes the general features of a target class. Discrimination compares the target class with other classes to find distinguishing features.

2. Support

Support of a rule A → B is the percentage of transactions in the database that contain both A and B.

Support(A → B) = P(A ∪ B) = (Transactions containing A and B) / (Total Transactions) × 100%

3. Confidence

Confidence of a rule A → B is the percentage of transactions containing A that also contain B.

Confidence(A → B) = P(B|A) = Support(A ∪ B) / Support(A) × 100%

4. Strong Association Rules

A rule is called strong if it satisfies both minimum support (min_sup) AND minimum confidence (min_conf) thresholds simultaneously. Only strong rules are considered interesting/useful.

Rule is STRONG if: Support(A → B) ≥ min_sup AND Confidence(A → B) ≥ min_conf

5. Data Generalization

Data generalization summarizes data by replacing low-level data values with higher-level concepts using a concept hierarchy. E.g., "Mumbai" → "Maharashtra" → "India". It allows analysis at different levels of abstraction.

6. Unsupervised Learning

Unsupervised learning works with unlabeled data. The algorithm discovers hidden structure, patterns, or groupings in data without any predefined output labels. Example: Clustering customers by purchasing behavior without predefined categories.

Support measures frequency; Confidence measures strength. Both must exceed thresholds for a rule to be "strong".

Q 8Discuss major issues/challenges in data mining.

Major Issues in Data Mining

1. Mining Methodology

Selecting appropriate mining techniques for different types of knowledge (classification vs clustering vs association) and data types.

2. User Interaction

Providing proper querying languages, visualization tools, and interactive exploration for non-expert users.

3. Efficiency and Scalability

Algorithms must scale to handle terabytes/petabytes of data within reasonable time using parallel/distributed computing.

4. Data Quality

Dealing with noisy, incomplete, inconsistent, and redundant data. Poor data quality leads to poor mining results.

5. Privacy and Security

Mining personal data raises ethical and legal concerns. Privacy-preserving data mining techniques are needed.

6. Diversity of Data Types

Mining structured, semi-structured, unstructured data (text, images, spatial, temporal, web) requires specialized methods.

7. Interpretability

Patterns discovered must be understandable by domain experts. Complex models (neural networks) are "black boxes".

8. Curse of Dimensionality

As dimensions increase, data becomes sparse and distance metrics lose meaning, making clustering and classification harder.

📌 Key exam point: Scalability and privacy are the two most critical modern challenges in data mining.

1. Data Cleaning

Fills missing values, smooths noisy data, identifies/removes outliers, resolves inconsistencies.

Missing Value Handling

Methods: • Ignore the tuple (if class label is missing) • Fill manually • Use global constant (e.g., "Unknown") • Use attribute mean/median • Use most probable value (Bayesian / decision tree) Example: Age field is blank → Replace with mean age of dataset

Noisy Data Smoothing

Binning Methods: • Equal-width binning: divide range into equal-width intervals • Equal-frequency binning: each bin has same number of values • Regression: smooth by fitting data to regression function Example: Salary values [29000, 30000, 28500, 100000 (outlier)] → Sort → 28500, 29000, 30000, 100000 → Bin: [28500, 29000, 30000] → replace with mean 29167

2. Data Integration

Combines data from multiple sources into a coherent data store. Challenges: entity identification (same entity in two databases), schema integration, handling redundancies.

Example: Customer table in CRM system + Purchase table in ERP → Integrate using customer_id as foreign key → Detect redundancy: if Age can be derived from DOB, remove Age

3. Data Transformation

Transforms data into appropriate forms for mining. Includes normalization, aggregation, generalization, attribute construction.

Min-Max Normalization: v' = (v - min_A) / (max_A - min_A) × (new_max - new_min) + new_min Z-Score Normalization: v' = (v - μ) / σ Example: Age 25, min=18, max=60 → (25-18)/(60-18) = 7/42 = 0.167

4. Data Reduction

Obtains a reduced representation that gives same or similar results. Methods: dimensionality reduction (PCA), numerosity reduction (sampling), data compression.

📌 Pre-processing typically consumes 60-80% of total data mining project time — "garbage in, garbage out".

Normalization — In Detail

Normalization scales attribute values to fall within a small specified range. It prevents attributes with large ranges from dominating those with small ranges in distance-based algorithms.

1. Min-Max Normalization

v' = [(v - min_A) / (max_A - min_A)] × (new_max_A - new_min_A) + new_min_A Maps value v to range [new_min_A, new_max_A] Preserves all relationships between original values

2. Z-Score (Zero-Mean) Normalization

v' = (v - μ_A) / σ_A μ_A = mean of attribute A σ_A = standard deviation of attribute A Useful when min/max are unknown or outliers exist

3. Decimal Scaling Normalization

v' = v / 10^j where j = smallest integer such that max(|v'|) < 1 Example: Values range from -986 to 917 j = 3 → divide all by 1000 -986 → -0.986, 917 → 0.917
📌 Min-Max is most commonly used. Z-score is preferred when data is normally distributed. Decimal scaling is simplest.
Q 12Define noise data. Enlist reasons for noise. Explain methods to deal with noise.

Noise Data

Noise refers to random errors or variance in a measured variable — data that is incorrect, irrelevant, or misleading in a dataset.

Reasons for Noise in Data Collection

  • Faulty data collection instruments (broken sensors, miscalibrated devices)
  • Human error during manual data entry
  • Data transmission errors (network packet loss)
  • Inconsistencies in naming conventions across sources
  • Deliberate manipulation / data corruption
  • System glitches during data logging

Methods to Deal with Noise

1. Binning

Sort data and divide into bins. Smooth by bin mean, median, or boundaries.

Example — Smoothing by bin boundary: Bin: [4, 8, 9, 15] → min=4, max=15 4 → 4 (closer to min) 8 → 4 (closer to min) 9 → 15 (closer to max) 15 → 15

2. Regression

Use linear or polynomial regression to fit a smooth function to the data, filtering out random noise.

3. Clustering-Based Outlier Detection

Group data into clusters. Data points that are far from all cluster centers are treated as noise/outliers and removed.

4. Wavelet Transform

Decomposes data signal into frequency components. Low-frequency components represent smooth patterns; high-frequency components represent noise. Threshold the high-frequency coefficients to denoise.

Q 13What is an outlier? Why is outlier mining important?

Outlier Definition

An outlier is a data object that deviates significantly from the rest of the objects in the dataset — it is inconsistent with the general behavior or model of the data. Outliers are also called anomalies, exceptions, or noise points.

Statistical definition: A value x is an outlier if: x < Q1 - 1.5 × IQR OR x > Q3 + 1.5 × IQR where IQR = Q3 - Q1 (Interquartile Range)

Types of Outliers

Point Outlier

A single data point that differs greatly from the rest. Most common type. E.g., salary of ₹10 crore in a ₹50k avg dataset.

Contextual Outlier

A data point is an outlier in a specific context but not otherwise. E.g., 35°C temperature is normal in June but outlier in December.

Collective Outlier

A collection of related data objects that are collectively anomalous. E.g., sudden spike in network traffic (DDoS attack).

Why Outlier Mining is Important

  • Fraud Detection: Unusual credit card transactions indicate fraud
  • Medical Diagnosis: Abnormal patient readings indicate disease
  • Network Intrusion Detection: Unusual access patterns signal cyber attacks
  • Quality Control: Defective products show outlier measurements
  • Sports/Performance Analysis: Identify exceptional athletes or equipment failures
  • Data Cleaning: Outliers may represent data entry errors that need correction
⚠️ Outliers should NOT always be removed — sometimes they represent the most valuable and interesting information (fraud, disease, discovery).
Q 14Explain the following terms: 1) Bias 2) Variance 3) Generalization 4) Outlier

1. Bias

Bias is the error introduced by approximating a real-world problem (which may be complex) with a simplified model. A model with high bias pays little attention to training data and oversimplifies the problem — this leads to underfitting.

High Bias → Underfitting → Model too simple → Low training AND test accuracy

2. Variance

Variance is the error from sensitivity to small fluctuations in the training dataset. A model with high variance memorizes training data including noise, but fails on new data — this leads to overfitting.

High Variance → Overfitting → Model too complex → High training accuracy, Low test accuracy

3. Generalization

Generalization is the ability of a learned model to perform well on new, unseen data that was not part of the training set. A well-generalized model captures the true underlying patterns rather than memorizing training examples.

Good Generalization = Low Bias + Low Variance (balance point)

4. Outlier

An outlier is a data point that deviates significantly from the majority of data. It can be caused by measurement errors, data entry mistakes, or genuinely rare events. In mining, outliers may represent fraud, disease, or exceptional performance.

Proximity Measures

Proximity measures quantify the degree of similarity or dissimilarity between two data objects. They are fundamental to clustering, classification (KNN), and anomaly detection algorithms.

Uses of Proximity Measures

  • Clustering: Group similar objects; K-Means uses Euclidean distance to assign points to clusters
  • KNN Classification: Find k nearest neighbors to classify a new point
  • Anomaly Detection: Data objects far from all others are anomalies
  • Recommendation Systems: Find users with similar preferences

Euclidean Distance — Detailed Explanation

Euclidean distance is the most commonly used proximity measure. It measures the straight-line distance between two points in n-dimensional space.

d(x, y) = √[Σᵢ(xᵢ - yᵢ)²] For 2D: d(x,y) = √[(x₁-y₁)² + (x₂-y₂)²] Example: Point A = (2, 4), Point B = (5, 8) d(A,B) = √[(2-5)² + (4-8)²] = √[(-3)² + (-4)²] = √[9 + 16] = √25 = 5

Minkowski Distance (Generalization)

d(x,y) = [Σᵢ|xᵢ - yᵢ|^h]^(1/h) h=1 → Manhattan (L1 norm) h=2 → Euclidean (L2 norm) h=∞ → Chebyshev (max dimension difference)
Q 16Define data cube and explain any 3 operations on it.

Data Cube

A data cube is a multi-dimensional data model used in OLAP (Online Analytical Processing) that allows data to be modeled and viewed in multiple dimensions. Each dimension represents an attribute, and each cell contains a measure (e.g., sales amount).

A 3D data cube: Time × Location × Product → Sales Each (time, location, product) combination has a sales value

Data Cube Operations

1. Roll-Up (Drill-Up)

Aggregates data by climbing up a concept hierarchy or by dimension reduction. Goes from lower level of detail to higher level.

Roll-Up Example: Day → Month → Quarter → Year (Time hierarchy) City → State → Country (Location hierarchy) Roll up from City to Country: sum up sales for all cities in each country

2. Drill-Down (Roll-Down)

The reverse of roll-up. Navigates from higher level to finer-grained data for more detail.

Drill-Down Example: Year → Quarter → Month → Day Sales by Year → Sales by Quarter (more detail)

3. Slice

Selects a single value for one dimension, resulting in a sub-cube with one fewer dimension.

Slice Example: Fix Time = "Q1 2024" Result: 2D cube of Location × Product for Q1 2024 only

4. Dice

Selects two or more values for multiple dimensions, resulting in a sub-cube.

Dice Example: Time IN (Q1, Q2) AND Location IN (Mumbai, Delhi) Result: Sub-cube with those specific values

5. Pivot (Rotate)

Rotates the data cube axes to provide an alternative presentation of the data.

📌 Roll-up = less detail (aggregation), Drill-down = more detail. Slice fixes one dimension, Dice fixes multiple.

Q 18Explain Support and Confidence measures with appropriate example.

Association Rule Mining Measures

Association rule mining finds interesting relationships between items in large transactional databases. Two key measures determine if a rule is interesting:

Support

Support measures how frequently an itemset appears in the database. It is the fraction of transactions containing the itemset.

Support(A → B) = Support({A,B}) = (# transactions with both A and B) / (Total # transactions) Example Dataset (5 transactions): T1: {Bread, Butter, Milk} T2: {Bread, Butter} T3: {Bread, Milk} T4: {Butter, Milk} T5: {Bread, Butter, Milk} Support(Bread → Butter): Transactions with both Bread AND Butter = T1, T2, T5 = 3 Support = 3/5 = 60%

Confidence

Confidence measures how often items in B appear in transactions that contain A. It is the conditional probability P(B|A).

Confidence(A → B) = Support({A,B}) / Support({A}) From above example: Support(Bread) = T1, T2, T3, T5 = 4/5 = 80% Support({Bread, Butter}) = T1, T2, T5 = 3/5 = 60% Confidence(Bread → Butter) = 60% / 80% = 75% Interpretation: 75% of transactions that have Bread also have Butter.

Lift (Additional Measure)

Lift(A → B) = Confidence(A → B) / Support(B) Lift > 1 → Positive correlation (B is more likely with A) Lift = 1 → Independent (no relationship) Lift < 1 → Negative correlation (B less likely with A)
📌 A rule A→B is "strong" only if Support ≥ min_sup AND Confidence ≥ min_conf. Both must be satisfied.

Q 20Using Apriori algorithm, find all frequent itemsets. (TID dataset: M,O,N,K,E,Y... min_sup=60%, min_conf=80%)

Apriori Algorithm

The Apriori algorithm is a classic algorithm for frequent itemset mining and association rule generation. It uses the Apriori Property: All non-empty subsets of a frequent itemset must also be frequent.

Apriori Property (Anti-Monotone)

If itemset {A, B} is NOT frequent → {A, B, C} CANNOT be frequent (Any superset of an infrequent set is infrequent → prune it!)

Step-by-Step Solution

Dataset: 5 transactions, min_sup = 60% → minimum count = 3

===== PASS 1: Generate C1 (1-itemsets) ===== Scan all transactions and count each item: A:1, C:2, D:1, E:4, I:1, K:5, M:3, N:2, O:3, U:1, Y:3 ===== L1: Frequent 1-itemsets (count ≥ 3) ===== {E}:4, {K}:5, {M}:3, {O}:3, {Y}:3 ===== PASS 2: Generate C2 from L1 ===== (Combine every pair from L1) {E,K}, {E,M}, {E,O}, {E,Y}, {K,M}, {K,O}, {K,Y}, {M,O}, {M,Y}, {O,Y} Scan transactions and count: {E,K}: T1,T2,T3,T5 → 4 ✓ {E,M}: T1,T3 → 2 ✗ {E,O}: T1,T2,T5 → 3 ✓ {E,Y}: T1,T2 → 2 ✗ {K,M}: T1,T3,T4 → 3 ✓ {K,O}: T1,T2,T5 → 3 ✓ {K,Y}: T1,T2,T4 → 3 ✓ {M,O}: T1 → 1 ✗ {M,Y}: T1,T4 → 2 ✗ {O,Y}: T1,T2 → 2 ✗ ===== L2: Frequent 2-itemsets ===== {E,K}:4, {E,O}:3, {K,M}:3, {K,O}:3, {K,Y}:3 ===== PASS 3: Generate C3 from L2 ===== (Merge pairs from L2 sharing same prefix) {E,K,O}: Check subsets {E,K}✓, {E,O}✓, {K,O}✓ → all frequent → include {K,O,Y}: Check {K,O}✓, {K,Y}✓, {O,Y}✗ → pruned! {E,K,M}: Check {E,K}✓, {E,M}✗ → pruned! Q 22How to improve efficiency of Apriori algorithm. Discuss in detail.

Bottlenecks of Basic Apriori

  • Multiple database scans (one per itemset level)
  • Huge number of candidate itemsets generated
  • Tedious workload of support counting

Efficiency Improvement Techniques

1. Hash-Based Technique

Use a hash table to filter out infrequent itemsets early during candidate generation.

During C1 scan, hash each 2-item combination into buckets. If bucket count < min_sup → all itemsets hashing to that bucket are infrequent → prune them. This reduces the size of C2 significantly without extra database scan.

2. Transaction Reduction

A transaction that does not contain any frequent k-itemset cannot contribute to frequent (k+1)-itemsets. Such transactions can be marked and ignored in subsequent scans.

If transaction T contains no frequent 2-itemsets → T cannot contribute to any frequent 3-itemset → Remove T from database for pass 3+

3. Partitioning

Divide the database into non-overlapping partitions. Find locally frequent itemsets in each partition (only 2 database scans total).

Phase 1: For each partition P, find locally frequent itemsets (1 scan) Phase 2: Count globally using candidate list from all partitions (1 scan) Key: A globally frequent itemset must be locally frequent in at least one partition

4. Sampling

Mine frequent itemsets on a sample of the database with a lower support threshold. Use the full database only to verify results.

Use sample S with min_sup' < min_sup to ensure we don't miss frequent itemsets Verify on full database once with the candidate list

5. Dynamic Itemset Counting (DIC)

Add new candidate itemsets at any point during the database scan, not just at the start of each pass. Reduces the number of database scans.

6. FP-Growth Algorithm

The most efficient alternative to Apriori. Compresses the database into an FP-Tree structure. Only 2 database scans needed. No candidate generation required.

FP-Growth advantages: • No candidate generation (no combinatorial explosion) • Only 2 database scans • Compressed FP-Tree fits in memory • Divide-and-conquer approach
📌 Hash-based technique is the most commonly asked efficiency improvement in exams. FP-Growth is the best overall alternative.
Q 23Discuss Hash-Based technique to improve efficiency of Apriori algorithm.

Hash-Based Technique

The hash-based technique was proposed by Park, Chen and Yu (1995) to reduce the number of candidate 2-itemsets during the Apriori algorithm, which is typically the largest and most expensive set to process.

Core Idea

While scanning the database to count 1-itemsets (C1), simultaneously hash each pair of items into a hash table. If the hash bucket count is below min_sup, then no 2-itemset that hashes to that bucket can be frequent — so we can prune the entire bucket's candidates.

Hash-Based Algorithm Steps

  1. During scan for C1: For each transaction T, generate all pairs (i,j) and hash them to bucket h(i,j)
  2. Increment the count of each hash bucket
  3. After scan: Any bucket with count < min_sup cannot contain any frequent 2-itemset → mark as invalid
  4. Generate C2: Only include 2-itemsets that hash to valid (high-count) buckets
  5. Scan database to get exact counts for C2 candidates
Hash Function Example: h(i, j) = (order(i) × 10 + order(j)) mod 7 Transaction {A, B, C, D}: Pairs: AB, AC, AD, BC, BD, CD h(A,B) = bucket 0 h(A,C) = bucket 1 ... etc. After full database scan: Bucket 0 count = 5 (≥ min_sup=3) → keep Bucket 3 count = 1 (< min_sup) → prune all candidates in bucket 3

Benefit

Hash-Based Pruning Effect on C2
📌 Hash-based technique is most effective for reducing C2 (2-itemsets) which is typically the largest candidate set.

3. Recall (Sensitivity / True Positive Rate)

Recall = TP / (TP + FN) Example: TP=80, FN=20 Recall = 80/100 = 80% "Of all actual spam, 80% were correctly identified"

4. F1-Score

F1 = 2 × (Precision × Recall) / (Precision + Recall) F1 = 2 × (0.889 × 0.80) / (0.889 + 0.80) F1 = 2 × 0.711 / 1.689 = 84.2% "Harmonic mean balances precision and recall"

5. Specificity (True Negative Rate)

Q 31Explain working of decision tree algorithm with suitable example.

Decision Tree

A decision tree is a tree-shaped classification model where each internal node represents a test on an attribute, each branch represents an outcome of the test, and each leaf node represents a class label.

Key Concepts

Information Gain

Measures the reduction in entropy after splitting on an attribute. Higher gain = better split attribute.

Entropy

Measures impurity/disorder of a dataset. Entropy=0 → pure node. Entropy=1 → maximum disorder.

Entropy(S) = -Σ pᵢ × log₂(pᵢ)
where pᵢ = proportion of class i in set S

For binary class (p positive, n negative):
Entropy(S) = -(p/(p+n))×log₂(p/(p+n)) - (n/(p+n))×log₂(n/(p+n))

Information Gain:
Gain(S, A) = Entropy(S) - Σ [|Sᵥ|/|S|] × Entropy(Sᵥ)
where Sᵥ = subset of S where attribute A has value v

Q 32Enlist steps of ID3 decision tree algorithm. Explain it with suitable example and generate the tree.

ID3 Algorithm (Iterative Dichotomiser 3)

ID3, developed by Ross Quinlan (1986), builds a decision tree by recursively selecting the attribute with the highest Information Gain at each node.

Steps of ID3

  1. Calculate Entropy of the entire dataset S
  2. For each attribute A, calculate Information Gain: Gain(S, A) = Entropy(S) - Σ weighted entropy of subsets
  3. Select attribute with highest Information Gain as the root/current node
  4. Create branches for each value of the selected attribute
  5. Repeat steps 1–4 recursively for each branch using the subset of data for that branch
  6. Stop when: all instances in a branch have the same class (pure), no more attributes, or no instances remain

ID3 Formulas

Entropy(S) = -Σᵢ pᵢ × log₂(pᵢ) Information Gain: Gain(S, A) = Entropy(S) - Σ_{v∈Values(A)} [|Sᵥ|/|S|] × Entropy(Sᵥ) Gain Ratio (C4.5 improvement): GainRatio(S, A) = Gain(S, A) / SplitInfo(S, A) SplitInfo(S, A) = -Σ [|Sᵥ|/|S|] × log₂(|Sᵥ|/|S|)

ID3 Limitations

  • Biased toward attributes with many values (high Gain doesn't always mean better split)
  • Cannot handle continuous attributes directly (needs discretization)
  • Prone to overfitting (deep trees memorize training data)
  • No tree pruning — C4.5 added pruning to fix this

Q 33Explain Tree Pruning techniques.

Tree Pruning

Tree pruning is the process of removing branches from a decision tree that provide little predictive power, in order to reduce overfitting and improve generalization on unseen data.

Why Pruning is Needed

A fully grown decision tree tends to overfit the training data — it creates branches for even noisy training examples. Pruning removes these unnecessary branches to create a simpler, more generalizable tree.

Types of Pruning

1. Pre-Pruning (Early Stopping)

Stop growing the tree early before it perfectly classifies the training set. Stop if:

  • Number of instances at a node falls below a threshold
  • Information gain at the node is below a threshold
  • Statistical test shows no significant difference (chi-square test)
Pre-Pruning: Stop splitting if Gain(S, A) < threshold Advantage: Fast, simple Disadvantage: May stop too early (horizon problem)

2. Post-Pruning (More Common)

Grow the full tree first, then remove or replace sub-trees from bottom up. More reliable than pre-pruning.

Methods: 1. Subtree Replacement Pruning: Replace a subtree with a leaf if accuracy doesn't decrease on validation set 2. Subtree Raising: Replace a subtree with its most used subtree 3. Cost-Complexity Pruning (CART): Minimize: C_α(T) = Cost(T) + α × |T| where |T| = number of leaf nodes, α = complexity parameter

3. Reduced Error Pruning

  1. Build full decision tree on training data
  2. Use a validation set separate from training and test sets
  3. For each internal node: replace the subtree with a leaf (majority class)
  4. If accuracy on validation set does NOT decrease → keep the pruned version
  5. Repeat until further pruning decreases accuracy
Before and After Pruning
📌 Post-pruning (especially Reduced Error Pruning) is more reliable than pre-pruning. CART uses Minimum Description Length (MDL) principle for pruning.
Q 34Explain Bayesian learning and inference with suitable example. / Explain Bayes' Theorem and Naïve Bayesian Classification.

Bayes' Theorem

Bayes' theorem describes the probability of an event based on prior knowledge of conditions related to that event. It is the foundation of Bayesian classification.

P(H|X) = P(X|H) × P(H) / P(X) Where: P(H|X) = Posterior probability of hypothesis H given evidence X P(X|H) = Likelihood: probability of observing X given H is true P(H) = Prior probability of H (before seeing X) P(X) = Evidence: probability of X (normalizing constant) For classification: H = class label, X = attribute values P(Cᵢ|X) = P(X|Cᵢ) × P(Cᵢ) / P(X) Classify X to class Cᵢ that maximizes P(Cᵢ|X)

Naïve Bayesian Classifier

The Naïve assumption: all attributes are conditionally independent given the class. This simplifies calculation dramatically.

P(X|Cᵢ) = P(x₁|Cᵢ) × P(x₂|Cᵢ) × ... × P(xₙ|Cᵢ) = Πₖ P(xₖ|Cᵢ) Classification rule: Classify X to Cᵢ if P(Cᵢ|X) > P(Cⱼ|X) for all j ≠ i Equivalently: maximize P(X|Cᵢ) × P(Cᵢ)

Why "Naïve"?

It is "naïve" because in reality, attributes are rarely fully independent. E.g., "sunny" and "hot" are correlated. But despite this oversimplification, Naïve Bayes works surprisingly well in practice (especially for text classification).

Example — Play Tennis Classification

New instance X = (Outlook=Sunny, Temp=Cool, Humidity=High, Wind=Strong) Predict: Play Tennis? (Yes or No) Training data: 9 Yes, 5 No (from Q31 dataset) P(Yes) = 9/14 = 0.643 P(No) = 5/14 = 0.357 Calculate P(X|Yes): P(Sunny|Yes) = 2/9 = 0.222 P(Cool|Yes) = 3/9 = 0.333 P(High|Yes) = 3/9 = 0.333 P(Strong|Yes) = 3/9 = 0.333 P(X|Yes) = 0.222 × 0.333 × 0.333 × 0.333 = 0.00823 Calculate P(X|No): P(Sunny|No) = 3/5 = 0.600 P(Cool|No) = 1/5 = 0.200 P(High|No) = 4/5 = 0.800 P(Strong|No) = 3/5 = 0.600 P(X|No) = 0.600 × 0.200 × 0.800 × 0.600 = 0.0576 Compare: P(Yes) × P(X|Yes) = 0.643 × 0.00823 = 0.00529 P(No) × P(X|No) = 0.357 × 0.0576 = 0.02056 0.02056 > 0.00529 → PREDICT: NO (Don't Play Tennis)

Advantages of Naïve Bayes

  • Fast, simple, and easy to implement

Q 36Explain Naïve Bayesian classifier with example. Why is it called Naïve?

Why "Naïve"?

The classifier is called "naïve" because it makes the naïve assumption of class conditional independence — it assumes that each attribute contributes independently to the probability of the class, with no dependencies between attributes. In real data, attributes are rarely truly independent (e.g., height and weight are correlated), but this simplification makes computation tractable and surprisingly effective.

Naïve Independence Assumption: P(X|Cᵢ) = P(x₁,x₂,...,xₙ|Cᵢ) = Πₖ P(xₖ|Cᵢ) Without this assumption, we would need P(x₁,x₂,...,xₙ|Cᵢ) which requires exponentially many parameters to estimate. With independence: only n × |C| parameters needed.

Naïve Bayes for Categorical Attributes

For each class Cᵢ: Compute: P(Cᵢ|X) ∝ P(Cᵢ) × Πₖ P(xₖ|Cᵢ) P(xₖ = v | Cᵢ) = (count of records with xₖ=v in class Cᵢ) / (count of records in class Cᵢ) Laplace Smoothing (to avoid zero probability): P(xₖ = v | Cᵢ) = (count + 1) / (total_in_class + |domain of xₖ|)

Naïve Bayes for Continuous Attributes (Gaussian)

P(xₖ = v | Cᵢ) = (1 / √(2π)σᵢₖ) × exp[-(v - μᵢₖ)² / (2σᵢₖ²)] where μᵢₖ = mean of attribute xₖ for class Cᵢ σᵢₖ = std dev of attribute xₖ for class Cᵢ

Complete Example — Loan Approval

Training Data: Credit Income Loan_Approved Good High Yes Bad Low No Good Low Yes Bad High No Good High Yes P(Yes) = 3/5 = 0.6, P(No) = 2/5 = 0.4 New case: Credit=Good, Income=Low → Approve? P(Credit=Good|Yes) = 2/3, P(Credit=Good|No) = 0/2 = 0 → use Laplace: 1/4 P(Income=Low|Yes) = 1/3, P(Income=Low|No) = 1/2 P(Yes|X) ∝ 0.6 × 2/3 × 1/3 = 0.133 P(No|X) ∝ 0.4 × 1/4 × 1/2 = 0.050 0.133 > 0.050 → APPROVE LOAN

K-Means Clustering Algorithm

K-Means partitions n data points into k clusters, where each point belongs to the cluster with the nearest centroid (mean).

Algorithm Steps

  1. Choose k (number of clusters) and randomly initialize k centroids
  2. Assign each data point to the nearest centroid using Euclidean distance
  3. Recalculate centroid of each cluster as the mean of all points assigned to it
  4. Repeat steps 2–3 until centroids no longer move (convergence) or max iterations reached
Distance: d(x, cᵢ) = √[Σⱼ(xⱼ - cᵢⱼ)²] Centroid Update: cᵢ = (1/|Cᵢ|) × Σ_{x∈Cᵢ} x Objective Function (Minimize): J = Σᵢ Σ_{x∈Cᵢ} ||x - cᵢ||² (Sum of Squared Errors)

Worked Example (k=2)

Data points: A(1,1), B(2,1), C(4,3), D(5,4), E(6,5) k=2, Initial centroids: C1=(1,1), C2=(6,5) Iteration 1 — Assign: A(1,1): d(C1)=0, d(C2)=√50=7.07 → Cluster 1 B(2,1): d(C1)=1, d(C2)=√41=6.40 → Cluster 1 C(4,3): d(C1)=√13=3.6, d(C2)=√8=2.83 → Cluster 2 D(5,4): d(C1)=√25=5, d(C2)=√2=1.41 → Cluster 2 E(6,5): d(C1)=√41=6.4, d(C2)=0 → Cluster 2 Update centroids: C1 = mean(A,B) = ((1+2)/2, (1+1)/2) = (1.5, 1) C2 = mean(C,D,E) = ((4+5+6)/3, (3+4+5)/3) = (5, 4) Iteration 2 — Assign with new centroids: A(1,1) → C1(1.5,1): d=0.5 vs C2(5,4): d=5 → Cluster 1 B(2,1) → C1: d=0.5 vs C2: d=4.24 → Cluster 1 C(4,3) → C1: d=3.2 vs C2: d=1.41 → Cluster 2 D(5,4) → Cluster 2, E(6,5) → Cluster 2 No change → CONVERGED Final: Cluster1={A,B}, Cluster2={C,D,E}

Effect of Outliers on K-Means

Original data: A(1,1), B(2,1), C(4,3), D(5,4), E(6,5) Outlier added: O(50,50) WITHOUT outlier: C1=(1.5,1), C2=(5,4) ← correct clusters WITH outlier O(50,50) in Cluster 2: C2 = mean(C,D,E,O) = ((4+5+6+50)/4, (3+4+5+50)/4) = (16.25, 15.5) Now C2 centroid is pulled far away! → Points C,D,E may be reassigned to C1 → Clusters become meaningless → Outlier O dominates centroid position

Q 42Differentiate agglomerative and divisive methods of clustering.

Hierarchical Clustering

Hierarchical clustering builds a dendrogram (tree structure) showing how clusters are merged or split at different levels of similarity.

Agglomerative (Bottom-Up)

Starts with each point as its own cluster. Iteratively merges the two closest clusters until all points form one cluster.

  1. Treat each data point as a single cluster (n clusters initially)
  2. Find the two closest clusters based on linkage criteria
  3. Merge them into a single cluster
  4. Update distance matrix
  5. Repeat until only one cluster remains or k clusters achieved

Divisive (Top-Down)

Starts with all points in one cluster. Iteratively splits the largest/most heterogeneous cluster until each point is its own cluster.

Q 46What do you mean by perceptron? Discuss single-layer and multi-layer perceptron.

Perceptron

A perceptron is the simplest form of an artificial neural network — a single neuron that takes multiple inputs, applies weights, sums them, and passes the result through an activation function to produce a binary output.

Output = f(Σᵢ wᵢxᵢ + b) where xᵢ = input features wᵢ = weights b = bias f = activation function (step function for basic perceptron) Step activation: output = 1 if (Σwᵢxᵢ + b) ≥ threshold, else 0

Single-Layer Perceptron (SLP)

A single-layer perceptron has only one layer of input nodes connected directly to one output node. It can only learn linearly separable patterns.

Single-Layer Perceptron
Learning Rule (Perceptron Update): wᵢ ← wᵢ + η × (target - output) × xᵢ where η = learning rate (0 < η ≤ 1) Limitation: Cannot solve XOR problem (not linearly separable)

Multi-Layer Perceptron (MLP)

An MLP adds one or more hidden layers between input and output. This allows learning of non-linear decision boundaries. Trained using the Backpropagation algorithm.

Multi-Layer Perceptron (3-layer feedforward network)

Backpropagation

Forward pass: Compute output layer by layer Compute error: E = ½(target - output)² Backward pass: Propagate error backward, update weights: δ_output = (target - output) × f'(net_output) δ_hidden = (Σ δ_output × w) × f'(net_hidden) Δwᵢⱼ = η × δⱼ × outputᵢ
📌 MLP can approximate any continuous function (Universal Approximation Theorem). More hidden layers = deeper network = more complex patterns learned.

Regression is a statistical method used to model and predict the relationship between a dependent variable (Y) and one or more independent variables (X). The output is always a continuous numerical value.

Q 49Explain mean, median and mode with example.

Measures of Central Tendency

These are statistical measures that describe the center of a data distribution.

Mean (Arithmetic Average)

The mean is the sum of all values divided by the number of values. It is the most commonly used measure of central tendency but is sensitive to outliers.

Mean (μ) = (Σxᵢ) / n = (x₁ + x₂ + ... + xₙ) / n Example: Salaries = {30000, 35000, 40000, 42000, 100000} Mean = (30000+35000+40000+42000+100000) / 5 = 247000 / 5 = ₹49,400 ⚠️ Note: The outlier 100000 pulls the mean up significantly

Median

The median is the middle value when data is sorted in ascending order. It is resistant to outliers and is a better measure for skewed distributions.

For odd n: Median = value at position (n+1)/2 For even n: Median = average of values at positions n/2 and n/2+1 Example: Sorted = {30000, 35000, 40000, 42000, 100000} n=5 (odd) → Median = value at position (5+1)/2 = 3rd value = ₹40,000 Even example: {10, 20, 30, 40} Median = (20+30)/2 = 25

Mode

The mode is the most frequently occurring value in the dataset. A dataset can have no mode, one mode (unimodal), two modes (bimodal), or multiple modes.

Example 1: {2, 3, 3, 4, 5, 3, 7} → Mode = 3 (appears 3 times) Example 2: {1, 2, 3, 4, 5} → No mode (all appear once) Example 3: {2, 2, 3, 3, 5} → Bimodal: Mode = 2 and 3 Example 4: Grades = {A, B, A, C, A, B} → Mode = A

Q 51Define time series database. Explain how to characterize time series data using trend analysis.

Time Series Database

A time series database is a database that stores sequences of values measured at successive points in time, with equal spacing between intervals. Each record includes a timestamp and one or more measured values.

Time series: T = {(t₁,v₁), (t₂,v₂), ..., (tₙ,vₙ)} where tᵢ = timestamp, vᵢ = observed value at tᵢ Examples: • Stock prices recorded every minute • Daily temperature readings over 10 years • Monthly sales data over 5 years • Hourly electricity consumption

Characteristics of Time Series Data

  • Autocorrelation: Values close in time tend to be correlated
  • Non-stationarity: Statistical properties (mean, variance) change over time
  • Seasonality: Regular patterns at fixed intervals
  • Trend: Long-term systematic movement

Trend Analysis

Trend analysis identifies the long-term direction (upward, downward, or stationary) of a time series by removing short-term fluctuations.

Methods for Trend Detection

1. Moving Average

SMA_k(t) = (x(t) + x(t-1) + ... + x(t-k+1)) / k Example (3-period MA): Month: Jan Feb Mar Apr May Jun Sales: 10 14 12 16 18 20 3-MA: - - 12 14 15.3 18 The 3-MA smooths out noise and reveals the upward trend.

2. Linear Trend Line (Least Squares)

Fit: Ŷₜ = a + bt where b = slope (trend direction and magnitude) a = intercept Calculate b = [nΣtY - ΣtΣY] / [nΣt² - (Σt)²] a = (ΣY - bΣt) / n

3. Decomposition

Time series = Trend + Seasonal + Cyclical + Irregular Additive model: Y = T + S + C + I Multiplicative: Y = T × S × C × I

Applications of Trend Analysis

  • Economic forecasting — GDP growth trends
  • Demand forecasting — seasonal sales patterns
  • Climate science — temperature trend over decades
  • Healthcare — tracking epidemic spread trends

Q 55What is MapReduce? Define Map and Reduce operations with suitable example.

MapReduce

MapReduce is a programming model and framework developed by Google for processing and generating large datasets in parallel across a distributed cluster of commodity hardware. It was introduced in 2004 and implemented as Apache Hadoop MapReduce.

Core Philosophy

Move computation to the data (not data to computation). The MapReduce framework automatically handles data partitioning, scheduling, fault tolerance, and inter-machine communication.

Two Operations

1. Map Operation

The Map function takes an input key-value pair and produces a set of intermediate key-value pairs. It processes each record independently — embarrassingly parallel.

Map: (key₁, value₁) → list of (key₂, value₂) Example — Word Count: Input: ("line1", "data mining is fun data") Map output: [("data",1), ("mining",1), ("is",1), ("fun",1), ("data",1)]

2. Reduce Operation

The Reduce function receives all intermediate values for a given key (after shuffle and sort phase) and merges them to produce a smaller set of values.

Reduce: (key₂, list of value₂) → list of (key₃, value₃) Example — Word Count: Input to Reducer: ("data", [1,1]) Reduce: sum all values Output: ("data", 2) Input: ("mining", [1]) Output: ("mining", 1)

Complete Word Count Example

Input Documents: Doc1: "data mining is fun" Doc2: "data analysis is useful" Doc3: "mining data reveals patterns" MAP PHASE (each doc processed in parallel): Doc1 → (data,1),(mining,1),(is,1),(fun,1) Doc2 → (data,1),(analysis,1),(is,1),(useful,1) Doc3 → (mining,1),(data,1),(reveals,1),(patterns,1) SHUFFLE & SORT (framework groups by key): analysis → [1] data → [1,1,1] fun → [1] is → [1,1] mining → [1,1] patterns → [1] reveals → [1] useful → [1] REDUCE PHASE (sum counts): analysis → 1 data → 3 fun → 1 is → 2 mining → 2 patterns → 1 reveals → 1 useful → 1
MapReduce Flow

Q 56Discuss the following terms: 1) Correlation analysis 2) Gain Ratio 3) Sequence Databases

1. Correlation Analysis

Correlation analysis measures the statistical degree of association between two variables. It identifies whether and how strongly pairs of variables are related.

Pearson Correlation Coefficient: r = Σ[(xᵢ-x̄)(yᵢ-ȳ)] / √[Σ(xᵢ-x̄)² × Σ(yᵢ-ȳ)²] Range: -1 ≤ r ≤ +1 r = +1 → Perfect positive (both increase together) r = -1 → Perfect negative (one increases, other decreases) r = 0 → No linear correlation

Uses in data mining: Feature selection (remove highly correlated features), detecting redundant attributes, understanding relationships before building models.

2. Gain Ratio

Gain Ratio is an improvement over Information Gain used in the C4.5 decision tree algorithm. It normalizes Information Gain by the Split Information to avoid bias toward attributes with many values.

Information Gain: Gain(S, A) = Entropy(S) - Σ [|Sᵥ|/|S|] × Entropy(Sᵥ) Split Information: SplitInfo(S,A) = -Σ [|Sᵥ|/|S|] × log₂(|Sᵥ|/|S|) Gain Ratio = Gain(S, A) / SplitInfo(S, A) Problem with Information Gain: An attribute like "Customer ID" has many values → high Information Gain but useless for generalization. Gain Ratio penalizes such attributes since SplitInfo is also high.

3. Sequence Databases

A sequence database stores sequences of ordered events or itemsets, where the order matters. Each record is a time-ordered sequence of events associated with an entity (customer, patient, user).

Example — Customer Purchase Sequences: Customer 1: (buy phone) → (buy case) → (buy screen protector) Customer 2: (buy laptop) → (buy bag) → (buy mouse) Customer 3: (buy phone) → (buy earphones) → (buy case) Sequential Pattern Mining finds frequent sub-sequences: Pattern: (buy phone) → (buy case) with support ≥ min_sup Applications: • Web clickstream analysis (page1 → page2 → page3) • DNA/protein sequence analysis in bioinformatics • Customer purchase path analysis in e-commerce • Log analysis in cybersecurity
Q 57Discuss the following terms: 1) Tree Pruning 2) Information Gain 3) Spatiotemporal Databases

1. Tree Pruning

Tree pruning reduces the size of a decision tree by removing sections (branches/sub-trees) that provide little predictive power, thereby reducing overfitting and improving generalization.

Pre-Pruning

Stop tree growth early using threshold on Information Gain, minimum instances per node, or chi-square test. Simple but may stop too early.

Post-Pruning

Grow full tree, then remove branches bottom-up if accuracy on validation set does not decrease. More reliable than pre-pruning.

Reduced Error Pruning: For each internal node n: 1. Replace subtree at n with leaf (majority class) 2. Measure accuracy on validation set 3. If accuracy ≥ original → keep pruned version 4. Repeat until further pruning reduces accuracy

2. Information Gain

Information Gain measures the reduction in entropy (uncertainty) achieved by splitting data on a particular attribute. Used in ID3 algorithm to select the best split attribute.

Entropy(S) = -Σᵢ pᵢ × log₂(pᵢ) Information Gain: Gain(S, A) = Entropy(S) - Σ_{v∈Values(A)} (|Sᵥ|/|S|) × Entropy(Sᵥ) Example: S = {9 Yes, 5 No}, Entropy(S) = 0.940 After splitting on Outlook (Sunny/Overcast/Rain): Gain(S, Outlook) = 0.940 - [5/14×0.971 + 4/14×0 + 5/14×0.971] = 0.940 - 0.694 = 0.246 Higher Information Gain → better attribute to split on

3. Spatiotemporal Databases

A spatiotemporal database stores data that has both spatial (location) AND temporal (time) components. It captures how spatial data changes over time.

Examples of Spatiotemporal Data: • GPS trajectory data: position(x,y) at each timestamp t • Weather station data: temperature, humidity at (lat,lng) over time • Traffic data: vehicle speeds at road segments over time • Epidemic tracking: disease cases at location over months Spatiotemporal Query Example: "Find all areas where air quality dropped below threshold between 6pm-9pm on weekdays in Q3 2024"

Key Operations

  • Trajectory analysis: Mining movement patterns of moving objects
  • Event detection: Finding when and where significant events occurred
  • Spatial co-location: Features that frequently co-occur in both space and time
  • Periodic pattern detection: Patterns that repeat at regular space-time intervals
